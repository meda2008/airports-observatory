# 按网址采集：当前执行约定

当前本地事实源是 catalog 加 `deploy-service/data/collector.sqlite` 中已批准的字段变更。不要用 revision=0 的旧种子覆盖后来核实的目录内容。

## 固定步骤

1. `node scripts/export-current-inventory.cjs` 生成字段缺口、来源、CSV。字段有值与材料充分是两个口径。
2. `node scripts/build-website-collectors.cjs` 按 HTTPS origin 生成 `collection/website-collectors/` 定义及 `work/website-collectors/index.json` 运行清单。稳定 ID 绑定网址；同源别名不自动共享事实或账号。
3. `node scripts/prepare-website-collection.cjs <新的runId>` 建立持久队列；已有 runId 续跑。只使用哈希校验后的原生帮助/政策链接，排除已读、已尝试、静态资源和用户要求跳过的站点。
4. 本机网页使用 Codex 内置 browser-use，向 `collection/workflow.mjs` 的 `runWorkflow` 注入该浏览器并传入 `websiteCollectors:true, runId, limit`。逐批执行到 `remaining=0`；验证、登录、条款、错误页记录断点并继续其他站点。不能另起外部浏览器。
5. 每次 `readRenderedDocument` 自带真实 `capturedAt`，保存脱敏可见正文、URL和哈希。页面自称更新时间另存 `pageUpdatedAt`。SPA路由变化、报价总额未刷新、缺时间或缺来源均拒绝入库。
6. `collection/url-collectors/<网址>.cjs` 只提取当前网址有原文字面依据的字段；特有只读操作放 `collection/site-recipes/`。新增解析规则必须保留旧资料、限定套餐/客户端范围，并验证反例。泛用采集器或一份配置不算该网站所有字段已验收。
7. 形成 `review-candidates.json` 与 `source-review.json` 后运行 `node scripts/admit-reviewed-observations.cjs <复核目录>`。检查源文件哈希、采集时间、字段内容、乐观版本及证据绑定；已批准后才改变数据库。复核收据存在时不得重写原复核输入。
8. 跨域帮助页须在复核输入提供 `originBindings`：当前官网原始页面文件与哈希、以及该页实际原生链接。它只证明该来源链接关系，不证明经营主体历史连续、不升级为独立信源、不转移登录授权。
9. 通过本地 `/api/changes`、受影响的搜索结果和浏览器页面验收，重导出字段盘点与注册表。网页无法证实速度、稳定性或经营连续性时保留未知。

## 本轮固化的执行细节（2026-11-03）

- 搜索摘要出现验证码词语不代表搜索页被拦；仅使用当前页面的实际验证控件或明确阻拦提示分类。
- 订单列表结合真实行与汇总判断，不能把“待支付0”或筛选标题当成待支付订单。未明确的状态继续保守阻断。
- 补单专用／请勿拍等商品不能作为首个套餐自动选择；需要明确普通套餐名称。`configurationOnly`在配置预览结束，不接受条款、不提交订单。
- 可以给任务显式指定`reuseTabId`继续用户已登录的同源页面，必须核对网址和allowedHosts；不自动猜测或复用其他站点标签页。
- 忍者云每次只读导航后等待当前可见页面，再检查路由、登录和验证状态。已保存的原文不因复跑成功而覆盖原采集时间，重复内容不重复批准。
- 新修复的登记流程把验证码请求时间记录在发送之前；分离邮箱布局仅选择实际可见且匹配的域名选项，不把完整邮箱重复拼接。Gmail先核对账号，连接器账号不匹配时改用已登录且匹配的内置会话；邮件搜索包括垃圾邮件，按邮件行打开并等待正文，隔离最新一封，验证码及其哈希均不落盘。重置/登录代码不得充作注册代码。
- 已批准的原文件也进入链接索引：同时核对复核输入哈希、入库收据、数据库批准提案/变更及原文件哈希，保留原采集时间；它只提供链接发现和去重，不会自动批准新事实。
- `prepare-website-collection`默认只追本轮报价/支付/退款缺项。按链接标题与主题区别财务问题和客户端教程；其他字段可显式传`requestedFields`，被本轮筛掉不等于永久放弃。
- 观察到的Apple Cloud自跳转页只做一次有限等待，无点击、解题或保护绕过；超时保存E0诊断并继续其他任务。详情标题和实际选中的套餐标签必须就绪。只有明确需要更新时间的文档才额外等待日期，避免每页固定空等。
- `scripts/prepare-literal-review.cjs <spec.json> <复核目录>`统一生成待入库材料及字面自核记录；它不自动入库，也不代表独立人工复核。仍须执行现有入库校验并保留收据。
