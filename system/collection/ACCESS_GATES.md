# 访问入口按钮

统一流程通过 `runWorkflow({ challengeConfirmations })` 调用
`completeConfirmedAccessGate`，原有断点继续由 `resumeClearedGates` 恢复。

- “我不是恶意刷站”和“点击继续访问”按精确可见按钮名适配。
- 这两类防刷站页面仍属于访问验证：只在当前标签页、当前完整 URL
  的当次确认有效时点击一次，不把长期授权当成每次验证的确认。
- 按钮重名、多个候选、出现协议勾选或密码表单时不点击。
- 点击前复查 URL；点击后重新分类。只有业务正文、登录页或注册页
  才能记为通过。仍是验证页时保留断点，继续其他任务，不循环点击。
- 精确名以外的按钮不根据“继续”“确认”模糊匹配；购买、付款、接受协议
  不属于访问按钮适配。
