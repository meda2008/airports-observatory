## 文件与构建

- `src/`：HTML、JS、CSS、SVG。客户端只筛选和呈现已经冻结的结果，不新增评分。
- `data/`：白名单公开投影；不含旧notes、账户、原始第三方整站HTML或完整本地归档。
- `dist/`：独立可托管的静态产物。`npm run build`和`npm run check`无需安装第三方依赖。
- `scripts/build-public-data.cjs`：在完整Airports本地项目内刷新公开投影，读取父项目的安全catalog并复用后台时效口径。托管端构建无需运行它，直接使用已生成的`data/`。
- `.openai/github-target.json`：已核实的发布目标及仓库ID；`.openai/github-publication.json`保存实际推送提交。没有将源凭证写入文件。
- `.publish/github/`：只含公开产物的发布checkout，不是主项目仓库。

```powershell
cd D:\AI_Projects\Airports\public-site
npm run build
npm run check
npm test
node scripts\publish-github.cjs
npm run verify:online
```

发布脚本只推送已通过校验的dist文件、README、换行配置和公开更正模板。以Gitblob字节和远端提交核对，不强推。必须等Pages返回`built`且绑定新提交，再核对线上文件；推送成功不等于发布完成。

## 版本核对与预测结算

公开页面`#/verify`提供按需的浏览器内SHA256核对、下载清单和离线工具。浏览器与Node调用同一个`src/integrity.mjs`策略，检查字节、来源引用、台账映射与边界。默认只检查随包清单的一致性；独立保存的清单哈希可检测清单与文件一起改写。两者都不证明事实、可信时间或付费业务可用，也不能从公开投影重算原始完整台账链。

```powershell
node scripts/verify-publication.cjs --directory dist
node scripts/settle-ledger.cjs --ledger data/public-ledger.json --adjudications examples/empty-adjudications.json --as-of 2026-10-26T08:00:00+08:00 --output settlement-new.json
```

`examples/current-settlement.json`是有明确复算时点的真实台账检查；`empty-adjudications.json`没有伪造结果或裁决者。当前245条弃判，0条可评分，Brier为空。未来计分要求事前点概率、结局操作定义、期限、冻结凭据、结果证据及独立裁决声明；区间中点、未知、失访和未到期不能进入评分。结构校验不认证实际独立性，完整契约在`examples/settlement.README.md`。测试数字均为明确标注的合成夹具，没有充当历史回测。

构建会重新核对冻结报告的输入字节和计算结果，只有完全一致才复制到公开版本。刷新结果时创建新报告并留存旧版，不能把构建时间写回预测做出日期。

`verify:online`绑定现有GitHub仓库ID与公开地址，读取当前发布记录后核对Pages提交、HTTPS、全部公开文件与私有路径阻断；每次报告追加到`.openai/online-verifications/`，失败记录保留。这不是持续监控任务，未创建计划运行或通知。
