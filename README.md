## 独立核对

网站的“版本核对”页可按需核对当前文件，也可下载公开工具。GitHub Download ZIP解压到新目录后，在该目录使用Node.js22或以上执行：

```text
node verify-publication.cjs --directory . --allow-repository-metadata
```

只有固定的README、更正模板和换行配置可以作为仓库元数据忽略；其他额外文件仍拒绝。外部保存的清单哈希可通过`--expected-manifest-sha256`对照。随包哈希不能证明事实、可信时间或原始完整台账链。
